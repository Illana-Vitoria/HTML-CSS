HTML & CSS - IFTM 🚀
Repositório destinado ao armazenamento de materiais e exercícios práticos em HTML5 e CSS3 produzidos durante o curso de Tecnologia em Sistemas para Internet no IFTM - Campus Uberlândia Centro.

📋 Sobre o Repositório
Este espaço contém a evolução dos meus estudos em desenvolvimento Web Front-End, abrangendo desde a estruturação semântica até a estilização avançada e responsividade.

🛠 Tecnologias Utilizadas
HTML5: Estruturação semântica de páginas.

CSS3: Estilização, Flexbox, Grid Layout e animações.

Design: Aplicação de conceitos de UI/UX (foco em temas modernos e responsivos).

📂 Organização do Conteúdo
Os arquivos estão organizados por módulos ou temas das aulas:

/projetos: Pequenas páginas ou componentes desenvolvidos durante o semestre.
